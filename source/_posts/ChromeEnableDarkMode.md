這篇介紹Chrome啟用DarkMode。

Step:
-----------------------------------------------------------------------------------------------
1.在Chrome瀏覽器輸入chrome://flags/#enable-force-dark

2.找到Force Dark Mode for Web Contents 將它Enabled

## 補充說明

### 這個功能做了什麼？

Chrome 的實驗性功能會把原本是淺色的網頁，自動轉換成深色顯示，即使網站本身沒有提供深色模式也能套用。

### 注意事項

- **實驗功能名稱可能會改變**：新版 Chrome 中，這個選項可能叫做「Auto Dark Mode for Web Contents」，可以在 chrome://flags 頁面上方的搜尋框輸入「dark」找到。
- **設定完要重新啟動 Chrome**：修改後頁面下方會出現「Relaunch」按鈕，點了才會生效。
- **有些網頁顏色可能怪怪的**：自動轉換有時會讓圖片或圖表顏色不自然，遇到時可以把選項改回 Default。

### 只想讓 Chrome 介面變深色

如果只想讓分頁列、選單等 Chrome 介面變成深色，不需要動實驗功能，在 Chrome「設定 → 外觀 → 模式」選擇深色即可。
