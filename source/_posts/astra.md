這篇介紹ASTRA佈景主題套用。

### How to use
```sh
1.安裝Starter Templates外掛

2.點選see library -> 選擇想要的佈景主題

3.安裝Elementor編輯器
```

## 補充說明：完整步驟

Astra 是 WordPress 上很受歡迎的輕量佈景主題，搭配官方的 Starter Templates 外掛，可以一鍵匯入整套設計好的網站範本。

### 1. 安裝並啟用 Astra

到 WordPress 後台的「外觀 → 佈景主題 → 安裝佈景主題」，搜尋 Astra，安裝後按「啟用」。

### 2. 安裝 Starter Templates 外掛

到「外掛 → 安裝外掛」，搜尋 Starter Templates，安裝並啟用。啟用後在「外觀」底下會多出 Starter Templates 的選項。

### 3. 選擇頁面編輯器與範本

進入 Starter Templates 後，先選擇要使用的頁面編輯器（例如 Elementor 或 WordPress 內建的區塊編輯器），再從範本庫挑選喜歡的網站範本。範本分成免費與付費兩種，付費範本會有標示。

### 4. 匯入範本

選好範本後按匯入，外掛會自動安裝需要的外掛（例如 Elementor），並匯入示範頁面、圖片與樣式設定。

### 注意事項

- **建議在新網站使用**：匯入範本會覆蓋原本的佈景主題自訂設定，已經有內容的網站請先備份。
- **匯入後再修改**：把示範文字和圖片換成自己的內容，再刪掉用不到的示範頁面。
