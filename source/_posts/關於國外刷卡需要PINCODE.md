這篇介紹關於國外刷卡需要PINCODE。

### Step
```sh
建議出發前國內向信用卡公司申請預借現金密碼 (4碼)
各家信用卡公司申請方式不同，要致電給客服人員協助。

信用卡預借現金密碼 = PIN CODE

這樣出國刷卡時，對方請你輸入PIN CODE就會刷過!
```

## 補充說明

### 哪些情況會需要輸入 PIN？

歐洲等地區普遍使用晶片加密碼的刷卡方式，尤其是以下情況：

- **自助售票機**：例如火車站、地鐵站的自動售票機。
- **自助加油站**：無人加油機通常要輸入 PIN 才能刷卡。
- **部分商店與餐廳**：店員把刷卡機拿給你時，可能會要求輸入密碼。

### 要注意的地方

- **預借現金密碼只用來刷卡**：申請這組密碼是為了刷卡時能通過驗證，不建議真的拿信用卡去 ATM 預借現金，因為會產生手續費和利息。
- **出發前確認**：每家發卡銀行的申請方式和生效時間不同，建議出國前幾週就先辦好。
- **多帶一張卡**：準備不同發卡組織的卡片，例如 VISA 和 Mastercard 各一張，遇到某張卡刷不過時還有備案。
